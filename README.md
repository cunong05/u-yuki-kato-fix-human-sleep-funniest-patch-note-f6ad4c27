One line of patch notes announcing that human sleep has been fixed:
funny enough to make a reader laugh, plausible enough to sit in a real
changelog.

## Entry

> Fixed a bug where humans needed coffee to boot up in the morning; sleep now charges overnight, coffee demoted to a hobby.

121 characters, one line.

## How it works

`main.py` writes the entry to `/output/entry.txt`, validates the
competition gate (UTF-8, 1–160 characters, not only white space, a single
line), then re-reads the file and validates what was actually written.
It exits 0 only when every check passes.

```sh
python3 main.py
```
